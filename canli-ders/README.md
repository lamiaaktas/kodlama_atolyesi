# Canlı Ders

Öğretmenin slayt ve sorularla canlı ders yaptığı, öğrencilerin kendi tabletlerinden katıldığı platform.
Kodlama Atölyesi'nden ayrı çalışır: kendi adresi, kendi sınıf listesi, kendi şifresi ve kendi Drive klasörü vardır.

## Kurulum (bir kez)
1. script.google.com → **Yeni proje**. Proje adını "Canlı Ders" yapın.
2. `canli-ders/Code.gs` dosyasının tamamını Code.gs'in içine yapıştırıp kaydedin.
3. İşlev listesinden **kurulum**'u seçip **Çalıştır**'a basın; izin isterse onaylayın.
4. **Dağıt → Yeni dağıtım → Web uygulaması** · Yürütme: **Ben** · Erişim: **Herkes** → Dağıt.
5. Verilen `/exec` adresini açın → **Öğretmen girişi** → şifre **1234** → Ayarlar'dan şifreyi değiştirin,
   Sınıflar'dan sınıfları ve öğrencileri ekleyin.

Ekran (Index.html) GitHub'dan okunur; ekran güncellemeleri en geç 5 dakikada siteye yansır.
Sunucu (Code.gs) değişirse yeniden yapıştırıp **Dağıt → Dağıtımları yönet → Yeni sürüm** ile dağıtın.
